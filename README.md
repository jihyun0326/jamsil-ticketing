# 잠실 티켓팅 연습

잠실야구장 좌석으로 티켓팅 흐름을 연습하는 웹 페이지입니다.
카운트다운 → 예매하기 → 대기열 → 보안문자 → 좌석 선택 → 예매확인

## 실행
`index.html`을 브라우저로 열면 됩니다. 설치나 서버가 필요 없습니다.

## 설정
시작 팝업에서 카운트다운(3·5초), 대기열 규모, 대기 진행 속도, 접속자 몰림, 희망 매수를 고릅니다.

## 동작 기준
화면의 "연습 규칙 보기"에서 순번 계산, 좌석 판매 순서, 연석·매진 기준 등을 볼 수 있습니다.

## 기록
반응속도·실패 횟수 등은 각 브라우저에만 저장됩니다.

---
연습용 화면이며 실제 예매·결제는 일어나지 않습니다. 대기열·좌석 판매 수치는 연습용 가정값입니다.
